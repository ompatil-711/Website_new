# Project instructions

- `01.html` is reference-only. Do not modify it.
- Keep the live website's white theme. Use vivid blue, orange and aqua accents, compact layouts and expressive Motion animations, as requested by the user; avoid dull colours and excessive empty space.
- Create replacement files before updating imports to point to them, so the running preview never references a missing file.
- Verify a production build after source changes and inspect the running preview when browser access is available. Check responsive layouts and card padding before handing back design work.
